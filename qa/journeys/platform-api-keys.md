Para qué: dar a otro programa una llave de API con los permisos justos, consultar la documentación y retirarla cuando ya no se usa.

## Punto de partida

- Un negocio con unas cuantas apps activadas y otro programa que quiere leer sus ventas.

## Recorrido

1. BASE-F91 — la documentación de la API, visible.
2. BASE-F90 — la documentación de la API.
3. BASE-F86 — una llave para el otro programa; se copia su token.
4. BASE-F89 — las llaves y qué puede cada una.
5. BASE-F87 — la llave, rotada.
6. BASE-F88 — la llave, revocada.
